## 美国云服务器的线路：CN2 GIA、AS9929、CMIN2、CU4837 分别是什么

搜这个词的人，一半是被这串缩写挡住的。四条线对应三家运营商的精品网，外加一条普通国际线路。

CN2 GIA（AS4809）是中国电信的精品国际出口，负载低，晚高峰稳，电信用户访问体验最好。贵，而且只有电信流量走这条线。

AS9929 是中国联通的工业互联网骨干网，联通回程质量好，带宽通常给得大。

CMIN2（AS58807）是中国移动的精品回程，移动用户友好。

CU4837 是联通的普通国际线路（AS4837），和 NTT、GTT 这类国际 Tier1 一样属于普通国际带宽。便宜，带宽给得大，海外访问快，国内回程在晚高峰会有波动。它跟 9929 都带「联通」两个字，价格接近，稳定性差一档，别混。

按用户选：用户主要走电信，优先 CN2 GIA；主要走联通，优先 9929；面向海外用户而不是国内回连，线路不关键，机房位置和带宽更重要。

机房位置这块，美国西海岸是国内访问美国的首选，太平洋海缆登陆点集中在这一带。要覆盖欧洲用户，就得选纽约、华盛顿这类东海岸节点：洛杉矶到欧洲 140–200ms，东海岸 60–100ms，差了一倍。

## 短板、退款规则，以及哪些人不该买

服务条款里有几条必须先看清楚。

不提供数据备份，服务器也没有配置数据冗余。磁盘阵列提升的是硬件可靠性，不等于备份。数据丢了自己负责，这一条官方写得很明确。

退款窗口是开通后 48 小时，超时不再受理。每台服务器只能退一次，按支付账户算，同一支付账户 3 天内最多退一台。促销、特价、活动产品不支持退款，续费订单、初装费、账户余额充值本身也不退，余额不能提现。想先试再决定，就别碰特价机。

IP 被墙不算服务故障，不构成退款理由。官方给的一次性保障是：支持自助更换 IP 的产品，从首次开通成功起 1 小时内，可以就已被墙的 IP 提交一次免费更换工单。之后换 IP 按配置收费，还有频次限制，滚动 72 小时最多 1 次、每个流量重置周期最多 2 次、每个账户每月最多 5 次。公告里也提过，重要会议期间和 6 月初是「墙高峰」，建议关机保 IP。跑代理类业务的，这项成本要提前算进去。

工单不是即时客服。官方明说不承诺即时响应，按提交顺序处理，重复提交反而会拖长队列。提交时把实例 IP、发生时间、报错原文、已经做过的排查一次给全，能少来回几轮。

下面这些情况别买：需要 99.99% SLA 的关键业务，官方没有给这个承诺；需要 HIPAA、SOC2 之类合规认证的项目；完全不懂中文的用户，面板和工单都是中文；要覆盖欧洲用户的，洛杉矶不是最优节点，得去看东海岸的机房。还有一种，每月要烧几 TB 流量又想要国内回程稳的，精品线路套餐的流量包撑不住，超了之后怎么计费，下单前先问清楚。

### 双 ISP 和原生 IP 有什么区别，我需要吗？

原生 IP 指 IP 的注册归属地和机房所在地一致，没经过二次分配，广告平台和搜索引擎对它的信任度更高。双 ISP 指这个 IP 段同时接入两家上游运营商，路由冗余更好，单条上游出问题时掉线概率低一些。做投放、做账号、做 SEO 的值得为它多花钱；纯建站、纯跑应用，普通原生 IP 就够。
